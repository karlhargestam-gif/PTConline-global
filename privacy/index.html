Privacy

How ptconline.global handles visits, videos and links. This notice is not legal advice.

This site

ptconline.global is a static catalog. It has no student account, no shopping cart and no form that stores what you type. Reading a page does not create a PTC profile.

The site is hosted on Vercel. The host may keep ordinary server logs, such as the address of the page, the time, and a browser identifier, in order to run and protect the service. PTC does not sell personal information.

This page describes how the site works. It is not legal advice. A counsel review is still needed before this notice is treated as final.

Videos and other sites

Class videos are played from Dropbox, YouTube or Vimeo. Those services can set their own cookies or collect usage data when a video loads or when you follow a link. Their policies govern that collection, not this page.

Links to Canvas, Mission One Eleven, Messenger College and PCG Global Missions leave this site. What you do there is covered by that organization.

Questions

To ask about this notice, use the Global Education page linked from the footer. If a direct PTC address is published later, this page will say so.
