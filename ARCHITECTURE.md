# Architecture

ptconline.global should stay a static multilingual catalog, with one learning system beside it for Mission One Eleven enrollment. Messenger College credit stays in the college’s own system.

## What the static site is for

The site is the front door. It answers, in English, Spanish and Portuguese:

- what PTC is
- which courses exist, who provides them, and how long they are
- what an open course contains this week
- how to study, how to ask Mission One Eleven for a certificate, and how to apply to Messenger College
- the privacy, terms and copyright notices

Pages are generated by `scripts/build.py` from `content/` and `src/partials/`. The generator writes HTML, and that HTML is what Vercel publishes. A pull request can be previewed without a custom Vercel build image.

A course is one JSON file. The same file feeds the three languages, the catalog card, the sitemap and the course page. Adding a language later means a new key on each string and a new column in the build, not a copied HTML tree written by hand.

The Messenger lock is not an access-control system. `"locked": true` tells the generator to publish the overview, the shared lock notice, and the apply button. It does not publish blocks. Anything committed under `assets/` can still be downloaded by URL, so college materials do not belong in this repository.

## What the static site cannot do

A file host cannot enroll a person, remember where they stopped, give a quiz, or issue a certificate that means something. A “lock” made of hidden HTML is not a lock. Video files linked with `?raw=1` from Dropbox also fail the students this catalog is for: no adaptive bitrate, poor seeking on slow networks, and a real chance the host cuts the link off.

## Recommended shape

| Piece | Role |
|---|---|
| This repository | Catalog, open courseware, legal pages, language switcher |
| One LMS for Mission One Eleven | Accounts, cohorts, progress, quizzes, certificates |
| Messenger College (Populi) | Credit courses and admission |
| PTC | Links out. It does not copy the grade book |

Keep the open readings and week outlines on the static site so a student on a poor connection can still see the path. Put the cohort — the people, the due dates, the submitted work — in the LMS.

**Moodle** fits if cost, offline use and language coverage matter more than a short setup. It is open source, it has a mobile app that can work offline, and the interface can be translated. Someone has to host it and administer it.

**LearnWorlds** (or a similar hosted school) fits if a polished app and payments matter more than cost and offline study. It is faster to open and weaker for low-bandwidth and multilingual cohorts.

**Populi** stays the system of record for Messenger College credit. PTC should keep listing those courses as overviews with “Apply at Messenger College”. Do not mirror Populi pages into this repo.

Single sign-on from the catalog to the LMS can come after the LMS exists. The catalog does not need accounts of its own.

## Later, not in this change

- Move class video off Dropbox raw links to a host with adaptive bitrate, and keep a low-resolution or audio-only file.
- French, then other languages, as another key in the content files rather than another hand-copied tree.
- A rights review before any textbook is treated as cleared for republication. Sizes are already printed on the download links so a large file is visible before someone on a slow connection taps it.
- Compress or split the largest PDFs (Acts, Building on Firm Foundations, The Core).
